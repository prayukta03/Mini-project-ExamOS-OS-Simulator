# ExamOS — Online Examination & OS Resource Management Simulator

## 📌 Project Overview

ExamOS is an interactive educational simulator designed to demonstrate Operating Systems concepts through an online examination and result processing system. It simulates examination-related tasks such as student login, question-paper delivery, answer submission, and result processing while illustrating how operating systems manage processes, synchronization, memory, and resources.

## 🎯 Problem Statement

An online examination platform must handle multiple students accessing examinations and submitting answers simultaneously. These activities create processing tasks, shared-resource access, and memory requirements. ExamOS demonstrates how Operating Systems concepts can help manage these activities efficiently and safely.

## 🚀 Key Features

* **CPU Scheduling:** Simulates examination-related tasks using CPU scheduling algorithms.
* **Producer–Consumer Synchronization:** Demonstrates coordination between answer submission and processing through synchronized queues.
* **Memory Management:** Visualizes memory allocation using First Fit, Best Fit, and Worst Fit techniques.
* **Resource Allocation Graph (RAG):** Represents resource allocation and helps illustrate potential deadlocks.
* **Interactive Dashboard:** Provides a visual interface for exploring Operating Systems concepts.
* **Performance Metrics:** Displays relevant scheduling and resource-management results, where implemented.

## 🧠 Operating Systems Concepts

1. Process Management and CPU Scheduling
2. Producer–Consumer Problem and Race Conditions
3. Memory Allocation Techniques
4. Resource Allocation Graphs and Deadlock Analysis
